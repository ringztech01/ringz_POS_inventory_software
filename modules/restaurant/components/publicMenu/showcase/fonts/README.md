# Showcase menu fonts

The guest menu's Showcase design (RingzPOS Digital Menu v2) uses two fonts.
They're kept here so the menu needs no internet: phones on the restaurant's
Wi-Fi get them from this server.

| File | Font | Characters |
| --- | --- | --- |
| `bricolage-latin.woff2` | Bricolage Grotesque, variable weight | Latin |
| `bricolage-latin-ext.woff2` | Bricolage Grotesque, variable weight | Latin Extended, including ₦ |
| `figtree-latin.woff2` | Figtree, variable weight | Latin |
| `figtree-latin-ext.woff2` | Figtree, variable weight | Latin Extended, including ₦ |

They come from Google Fonts, taken from the design's offline preview
("RingzPOS Digital Menu v2 - Offline Preview.html").

Both fonts are under the SIL Open Font License 1.1, which allows bundling
them with software:

- Bricolage Grotesque: © The Bricolage Grotesque Project Authors
